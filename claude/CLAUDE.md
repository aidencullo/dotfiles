# Global Claude Instructions

## Agent Usage

- Use agent teams (parallel subagents) whenever possible to maximize performance

## Communication Style

- Be succinct - answer in just a few sentences unless asked for more detail
- Get straight to the point without lengthy explanations

## Version Control

- Always version control projects with GitHub
- When creating a new repository, make it public by default
- Always create pull requests as drafts initially
- Always enable "Delete source branch" option
- Always enable "Squash commits" option
- Push changes without asking for permission
